# Robo 0.1：增量实现与验收范围

日期：2026-09-15。基础提交：`4cc205b9aaa7923600199112092eb5d5bbc0cd32`（CLI 2.0.0）。

用户要求与工作区 `docs/robo-product-brief.md`、`docs/robot-use-harness.md`（尤其第 9 节）是实现依据。关联任务已读取。README 和三份未提交的 Robo/Roboworld 文档属于原有工作区修改，保留且不纳入本次实现提交。

| 要求 | 实现/证据 | 范围 |
|---|---|---|
| MHS 接入 | 官方研究预览页面与官网核实；`robo mhs-status`；`host --backend mhs` 明确拒绝 | 真实规范、SDK、版本和硬件均未取得；不宣称 MHS 集成 |
| 模型与本地双循环 | CLI 文件工具生成程序；独立宿主执行像素感知与反馈控制 | 模型无需参与每个控制周期 |
| 独立执行宿主 | Unix socket、SQLite、受监管子进程、增量事件、提交去重、重连、取消 | macOS 本地单用户、单模拟工作单元 |
| 不可变 ProgramVersion | 显式源文件清单、vendored Python 依赖、冻结 stdlib/native/SDK、解释器哈希 | 无环境 site-packages，无 pip 在线安装；系统动态库属平台依赖 |
| ExecutionJob 与约束 | 持久 request/job ID、程序版本、设备权限、参数、共享工作区占用、墙钟/CPU/RSS/日志/动作预算 | RSS 为宿主采样上限，非硬内存预留；无硬实时承诺 |
| 多模态 | 图像内容寻址、时间/坐标/标定、工具消息、压缩、可携媒体的会话导入导出、Chat Completions 图像转换 | PNG/JPEG/WebP 与时间帧序列；无原生视频协议 |
| 物理验证 | 动作后 3 次编码器观察，独立计算对准误差并保存证据 | 模拟验证，不代表实机或视觉可靠性测量 |
| 不确定结果 | 命令意图先写入、ID 去重、丢回执后查询+现场核对；未知时禁止新动作 | 不承诺真实设备 exactly-once |
| 恢复/取消 | 客户端离开继续有界运行或 5 秒租约过期取消；宿主重启中断旧任务、重新观察、不重放 | 无通用暂停/恢复运动；显式支持两种断连策略 |
| 兼容旧 CLI | 原 `agent-harness` 保持 2.0.0；新增 `robo` 入口与可选 `--robo-home` | 原有文本会话 schema v1 可读 |

实施顺序：核实官方依赖 → 独立模拟执行闭环 → agent 工具与多模态 → 实际进程/HTTP 验证与回归 → 双路审查。
