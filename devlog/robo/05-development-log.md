# Robo 开发日志

## 2026-09-15：最小模拟闭环

1. 阅读产品定位、技术设计（尤其第 9 节）及关联任务。以 CLI 2.0.0 的 `4cc205b` 为基础，未覆盖 README 与已有设计文档修改。
2. 获取 Anthropic 公告和 MHS 官网。确认申请制研究预览，没有可取得并固定的公开 SDK/规范版本。记录真实 MHS、硬件和模型凭据阻塞；继续模拟开发。
3. 增加独立 Unix socket 执行宿主、SQLite 记录、ProgramVersion/ExecutionJob、动作去重/核对、程序/库/SDK 固定、macOS worker 沙箱和资源监管。
4. 实现 64×64 模拟相机与低速二维台。程序用本地 RGB centroid 感知，在每次观察后作有界修正；模型不在快速循环的每一步。
5. 增加图像引用、多模态会话格式、携带媒体的导出/导入、Chat Completions 帧转换和 agent 短工具。复用既有编辑、Diff/undo、权限、provider、预算和 CLI。
6. 首次运行发现 copied venv 启动器沙箱路径及 macOS RLIMIT_AS 限制。改为基础解释器精确规则与宿主 RSS 采样上限，明确并非硬实时或内存预留。
7. 演示验证：错误方向程序退出码 0 但物理失败；修正程序本地闭环收敛，物理误差约 0.18 mm（模拟）。注入回执丢失，查询核对后继续，无重复动作。
8. 22 项初始 Robo 测试通过。补充非阻塞 worker 返回通道、设备 revision 检查（其他客户端取图不会打断有效本地反馈）、提交原子记录和会话恢复 lookup。
9. 保存首个实现提交 `36cc451`，按 code-review 技能进行独立 Standards/Spec 两路审查。发现并修复宿主死亡孤儿 worker、模型请求取消延迟、长轮询错误续租、跨 job 未知动作约束和推理前现场摘要缺失。针对性测试加旧实验引擎共 51 项通过。
10. 需求复核又发现恢复任务未登记现场摘要的问题，已统一正常结果和恢复的 remember_job，并在下一次真实模型请求中验证恢复的 job/status/version/cursor。
11. 全量测试首先发现测试命名空间冲突、旧引擎 copied venv 启动器问题。分别以独立测试包和共享 launcher helper 修复，保留原有权限限制。最终结果及构建/安装/演示证据见 `04-validation.md`。

没有使用真实模型凭据，没有连接真实设备，也没有提交 MHS 预览申请。真实集成未完成，所需条件见 `01-mhs-research.md`。
